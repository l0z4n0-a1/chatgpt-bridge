# Code of Conduct

This project follows a short, practical version of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In one sentence

Be kind. Discuss code, not people. Help newcomers. If something feels off, say so calmly and move on.

## What we expect

- Treat everyone with basic respect.
- Critique ideas, not the people holding them.
- Use clear, professional language. No slurs, harassment, or sustained personal attacks.
- Assume good faith. Most disagreements are misunderstandings.
- When wrong, say so. When someone else is wrong, point it out without making it personal.

## What's not OK

- Sexualized language or imagery.
- Trolling, doxxing, or sustained disruption.
- Public or private harassment.
- Publishing others' private info without permission.

## Enforcement

If you witness or experience behavior that violates this, email **fluxmind.ia@gmail.com**. Reports stay confidential.

The maintainer may, depending on severity:
- Ask for a clarifying edit.
- Issue a private warning.
- Ban from the repo (issues, PRs, discussions).

## Scope

This applies in any project space — issues, PRs, discussions, commits, anywhere bearing the `chatgpt-bridge` name.
